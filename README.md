# 🍽️ Bisht Garhwali Restaurant (बिष्ट गढ़वाली रेस्टोरेंट)

A responsive, interactive online food ordering and restaurant showcase website built for college project presentation.

---

## 📌 Project Overview
- **Project Name:** Bisht Garhwali Restaurant Web Application
- **Type:** Frontend Web Development Project
- **Target Audience:** Restaurant Customers, College Faculty & Evaluators
- **Platform:** Cross-platform (Mobile, Tablet, Desktop)

---

## ✨ Features
1. **Interactive Digital Menu:**
   - Categorized food items (Fast Food, Chinese, Veg, Non-Veg, Egg Special, Drinks, Desserts).
   - Real-time search filter to quickly find any food item.
2. **Shopping Cart Management:**
   - Add food items to cart with single click.
   - Increment / decrement quantity or remove items dynamically.
   - Live total price and item counter updates.
3. **Demo Order Checkout:**
   - Order summary preview with total calculation.
4. **Responsive & Modern Design:**
   - Clean, restaurant-themed aesthetic with warm colors.
   - Mobile-first adaptive layout with smooth animations.
5. **QR Code Enabled:**
   - Scan QR code using any smartphone camera to instantly access the live website.

## 💻 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/bp90962-arch/bisht-restaurant.git
   ```
2. Navigate into the project directory:
   ```bash
   cd "Bisht Restaurant"
   ```
3. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Brave).
